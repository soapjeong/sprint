# 폰에 DormX 앱 설치하기 (안드로이드)

PC 를 켜 두지 않아도 앱이 돌아가게, **서버를 무료로 올리고 → 앱을 APK 로 빌드해서 → 폰에 설치**합니다.
처음 한 번만 하면 되고, 넉넉히 40분쯤 걸립니다. 돈은 들지 않습니다.

```
① Neon(무료 DB)  →  ② Render(무료 서버)  →  ③ 앱에 서버 주소 넣기  →  ④ EAS 로 APK 빌드  →  ⑤ 폰에 설치
```

> PowerShell 에서는 `npm` / `npx` 대신 **`npm.cmd` / `npx.cmd`** 를 쓰세요. 그냥 `npx` 는 보안 정책 때문에 막힐 수 있습니다.

---

## ① Neon — 기록을 담아 둘 무료 데이터베이스

Render 의 무료 데이터베이스는 30일 뒤에 사라지기 때문에, DB 만 Neon 을 씁니다(무료, 기한 없음).

1. <https://neon.tech> 가입 (깃허브 계정으로 하면 빠릅니다)
2. **Create project** → 이름 `dormx`, 리전은 `Asia Pacific (Singapore)` 정도면 충분합니다
3. 만들어지면 **Connection string** 을 복사합니다. 이렇게 생겼습니다:

   ```
   postgresql://neondb_owner:비밀번호@ep-xxxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
   ```

   이 줄을 메모장에 붙여 두세요. **②에서 씁니다.**

---

## ② Render — 앱이 접속할 서버

1. <https://render.com> 가입 (깃허브 계정 권장)
2. **New +** → **Blueprint** → 이 저장소(`sprint`) 선택 → 브랜치는 작업 중인 브랜치
   - 저장소 안의 `render.yaml` 을 읽고 서비스를 알아서 만듭니다.
3. 환경변수 세 개를 채우라고 나옵니다. 이렇게 넣습니다:

   | 이름 | 넣을 값 |
   |---|---|
   | `DATABASE_URL` | ①에서 복사한 Neon 연결 문자열 |
   | `ADMIN_TOKEN` | 관리자 페이지 비밀번호처럼 쓸 긴 문자열 (예: `dormx-admin-9f3k2p`) |
   | `INGEST_API_KEY` | 기기(브리지)가 쓸 키 (예: `dormx-ingest-7a1x5c`) |

   > 두 토큰은 아무 값이나 길게 지으면 됩니다. 기본값을 그대로 두면 **서버가 일부러 켜지지 않습니다**(보안).
   > 나중에 브리지를 돌릴 때 `INGEST_API_KEY` 가 필요하니 메모해 두세요.

4. **Apply** → 3~5분 기다리면 주소가 나옵니다:

   ```
   https://dormx-sleep-api.onrender.com
   ```

5. 브라우저에서 그 주소를 열어 상태 페이지가 보이면 성공입니다.
   관리자 페이지는 `그 주소 + /admin/` 입니다. (예: `https://dormx-sleep-api.onrender.com/admin/`)

> **무료 서버의 성질 하나:** 15분쯤 아무도 안 쓰면 잠듭니다. 그다음 첫 요청은 깨어나느라 최대 1분 걸립니다.
> 앱은 이 경우 "서버를 깨우는 중이에요" 를 띄우고 알아서 기다립니다. 고장이 아닙니다.

## ③ 앱에 서버 주소 넣기

`mobile/app.json` 에서 **한 줄만** 고칩니다.

```json
"extra": {
  "defaultServerUrl": "https://dormx-sleep-api.onrender.com"
}
```

저장하고 커밋합니다. (EAS 는 커밋된 내용으로 빌드합니다)

```powershell
git add mobile/app.json
git commit -m "서버 주소 설정"
```

> 설치한 뒤에도 바꿀 수 있습니다. 앱 첫 화면에서 **달 아이콘을 1초쯤 길게 누르면** 주소 입력칸이 나옵니다.

## ④ APK 빌드하기

```powershell
cd C:\Users\grace\sprint\mobile

npx.cmd eas-cli@latest login      # Expo 계정 (없으면 expo.dev 에서 무료 가입)
npx.cmd eas-cli@latest init       # 이 앱의 프로젝트 ID 를 만들어 app.json 에 넣어줍니다
npx.cmd eas-cli@latest build --platform android --profile preview
```

- `preview` 프로필은 **APK** 로 만듭니다. 스토어를 거치지 않고 바로 설치할 수 있는 형식입니다.
- 커밋 안 한 변경이 있으면 "커밋할까요?" 하고 묻습니다. `yes` 로 답하면 됩니다.
- 무료 대기열이라 10~25분쯤 걸립니다. 다 되면 **다운로드 링크와 QR 코드**가 나옵니다.
  (창을 닫아도 <https://expo.dev> → 내 프로젝트 → Builds 에서 다시 볼 수 있습니다)

## ⑤ 폰에 설치하고 확인하기

1. 폰에서 그 **QR 을 찍거나 링크를 엽니다** → `.apk` 가 내려받아집니다.
2. 열면 "이 출처의 앱 설치 허용" 을 묻습니다 → 허용 → 설치.
   (Play 스토어를 거치지 않아서 나오는 경고입니다. 5명 이하 배포에서는 이 방식이 정상입니다)
3. 앱을 열고 **회원가입** → 닉네임 2~16자, 비밀번호 4자 이상.
4. 홈 화면이 뜨면 성공입니다. 아직 기기를 안 붙였으면 시작 버튼 아래가 **"기기 미등록"(빨강)** 으로 보입니다.

여기까지가 "앱이 폰에서 도는지" 확인입니다.

## 실제 기기까지 연결해서 보려면

기기(ESP32)는 아직 **USB 로 PC 에 연결**돼 있어야 합니다. 브리지 프로그램이 시리얼 값을 받아 서버로 올립니다.

```powershell
cd C:\Users\grace\sprint
python serial_csv_logger.py --server https://dormx-sleep-api.onrender.com --api-key <INGEST_API_KEY>
```

- 기기를 켜면 브리지가 기기 ID(`DORMX-...`)를 서버에 알립니다.
- 앱에서 **"기기 미등록"을 누르면** 그 기기가 목록에 뜨고, 누르면 내 계정에 연결됩니다.
- 그다음부터 앱의 시작 버튼이 기기의 start 를 대신합니다.

> 이 USB 연결을 없애려면 ESP32 에 Wi-Fi 를 붙여 기기가 직접 서버로 올리게 해야 합니다. 필요하면 말씀해 주세요.

## 자주 막히는 곳

| 증상 | 이유와 해결 |
|---|---|
| 앱에서 "서버에 연결할 수 없습니다" | 주소 오타이거나 `https://` 를 빠뜨린 경우가 대부분입니다. 폰 브라우저로 그 주소를 열어보세요. |
| 로그인이 30초 넘게 걸림 | 무료 서버가 자다 깨는 중입니다. 정상이며 한 번 깨면 그다음은 빠릅니다. |
| Render 로그에 `ADMIN_TOKEN ...` 하고 서버가 죽음 | 토큰 환경변수를 안 넣었습니다. ②의 3번을 확인하세요. |
| `npx : 이 시스템에서 스크립트를 실행할 수 없으므로` | `npx.cmd` 로 쓰거나, PowerShell 에서 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 한 번 실행하세요. |
| 앱을 고쳤는데 폰에 반영이 안 됨 | APK 는 빌드 시점의 코드로 굳습니다. ④를 다시 돌려 새 APK 를 설치하세요. |
| 설치할 때 "앱이 설치되지 않음" | 예전 APK 가 남아 있으면 지우고 다시 설치하세요. |
