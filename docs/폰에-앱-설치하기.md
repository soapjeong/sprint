# 폰에 DormX 앱 설치하기 (안드로이드)

PC 를 켜 두지 않아도 앱이 돌아가게, **서버를 무료로 올리고 → 앱을 APK 로 빌드해서 → 폰에 설치**합니다.
처음 한 번만 하면 되고, 넉넉히 40분쯤 걸립니다. 돈은 들지 않습니다.

```
① Neon(무료 DB)  →  ② Render(무료 서버)  →  ③ 앱에 서버 주소 넣기  →  ④ EAS 로 APK 빌드  →  ⑤ 폰에 설치
```

> PowerShell 에서는 `npm` / `npx` 대신 **`npm.cmd` / `npx.cmd`** 를 쓰세요. 그냥 `npx` 는 보안 정책 때문에 막힐 수 있습니다.

## ① Neon — 기록을 담아 둘 무료 데이터베이스

Render 에도 무료 데이터베이스가 있지만 **30일 뒤 만료**됩니다. 기록이 사라지면 안 되니 DB 만 Neon 을 씁니다(무료, 기한 없음).

### 1-1. 가입

1. <https://neon.tech> → 오른쪽 위 **Sign up**
2. **Continue with GitHub** (깃허브 계정으로 하면 비밀번호를 새로 안 만들어도 됩니다)
3. 이름·용도를 묻는 화면이 나오면 아무거나 골라 넘어갑니다.

### 1-2. 프로젝트 만들기

가입하면 바로 프로젝트 만들기 화면이 나옵니다. 안 나오면 대시보드에서 **New project**.

| 칸 | 넣을 값 |
|---|---|
| Project name | `dormx` |
| Postgres version | 기본값 그대로 |
| Cloud service provider | `AWS` |
| Region | `Asia Pacific (Singapore)` |

**Create project** 를 누릅니다. 10초쯤 걸립니다.

> 리전은 서울에서 가장 가까운 싱가포르를 고릅니다. ②의 Render 도 같은 싱가포르로 맞추면 서버↔DB 가 빨라집니다.

### 1-3. 연결 문자열 복사하기 — 여기가 중요합니다

프로젝트가 만들어지면 **Connect to your database** 라는 카드가 뜨고, 그 안에 한 줄짜리 문자열이 있습니다.

```
postgresql://neondb_owner:AbCd1234EfGh@ep-cool-boat-a1b2c3-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
```

- Database / Role 는 기본값(`neondb`, `neondb_owner`) 그대로 둡니다.
- **비밀번호가 `••••••` 로 가려져 있으면** `Show password` 를 켜고 복사하세요. 가려진 채로 복사하면 `••••` 가 그대로 붙어 나중에 접속이 실패합니다.
- 오른쪽 **Copy** 버튼으로 복사해 메모장에 붙여 둡니다.

**복사한 줄이 이런지 확인하세요.**

- `postgresql://` 로 시작하는가
- `@` 앞의 비밀번호가 점(`•`)이 아니라 실제 글자인가
- 끝에 `?sslmode=require` 가 붙어 있는가 — 없으면 직접 붙이세요
- 중간에 `-pooler` 가 들어 있어도 괜찮습니다

> 이 창을 닫아도 대시보드 → 프로젝트 → **Connect** 에서 다시 볼 수 있습니다.
> 다만 비밀번호는 다시 안 보여줄 수 있는데, 그때는 **Reset password** 로 새로 만들어 쓰면 됩니다.

### ✅ ①이 끝났는지 확인

메모장에 `postgresql://` 로 시작하는 긴 한 줄이 있고, 비밀번호가 글자로 보인다.

## ② Render — 앱이 접속할 서버

### 2-1. 가입

1. <https://render.com> → **Get Started** → **GitHub** 로 가입
2. 무료 플랜은 카드 등록을 요구하지 않습니다. 혹시 카드를 요구하는 화면이 나오면 멈추고 알려주세요.

### 2-2. 저장소 연결

1. 대시보드 오른쪽 위 **New +** → **Blueprint**
2. 처음이라면 깃허브 연결 화면이 나옵니다 → **Connect GitHub** → 깃허브 로그인
3. "Install Render" 화면에서 **Only select repositories** 를 고르고 **`soapjeong/sprint`** 만 선택 → **Install**
4. 저장소 목록에 `sprint` 가 보이면 **Connect**

### 2-3. 브랜치 고르기 — 여기서 가장 많이 틀립니다

설정 화면의 **Branch** 를 반드시 이렇게 바꿉니다.

```
claude/esp32-sleep-temp-optimizer-g03qjc
```

> `main` 에는 서버 코드도, `render.yaml` 도 없습니다. `main` 그대로 두면
> "render.yaml 을 찾을 수 없다" 며 실패합니다. **드롭다운에서 위 브랜치를 고르세요.**

Blueprint Name 은 아무거나(`dormx`) 좋습니다.

### 2-4. 환경변수 세 개 채우기

`render.yaml` 이 읽히면 `dormx-sleep-api` 서비스와 함께 **값을 입력하라는 칸 세 개**가 나옵니다.

| 이름 | 넣을 값 |
|---|---|
| `DATABASE_URL` | ①에서 복사한 Neon 연결 문자열 (한 줄 통째로) |
| `ADMIN_TOKEN` | 관리자 페이지에 들어갈 때 쓸 긴 문자열. 예: `dormx-admin-9f3k2p7q` |
| `INGEST_API_KEY` | 기기(브리지)가 쓸 키. 예: `dormx-ingest-7a1x5c4v` |

- 두 토큰은 **아무 값이나 길게** 지으면 됩니다. 영문·숫자·하이픈만 쓰세요.
- 기본값이나 빈칸으로 두면 **서버가 일부러 켜지지 않습니다**(아무나 관리자 페이지에 들어오는 걸 막기 위해서입니다).
- `INGEST_API_KEY` 는 나중에 브리지를 돌릴 때 또 필요하니 메모장에 남겨 두세요.

리전을 고르는 칸이 있으면 **Singapore** 로 맞춥니다.

### 2-5. 배포

**Apply**(또는 **Deploy Blueprint**)를 누르면 서비스가 만들어지고 바로 배포가 시작됩니다.

- 서비스 이름을 눌러 **Logs** 탭을 보면 진행이 보입니다.
- Docker 이미지를 만드는 첫 배포는 **3~7분**쯤 걸립니다.
- 로그 마지막에 이렇게 나오면 성공입니다:

  ```
  ==> Your service is live 🎉
  ```

주소는 서비스 페이지 맨 위에 있습니다.

```
https://dormx-sleep-api.onrender.com
```

> 이름이 이미 쓰이고 있으면 `dormx-sleep-api-a1b2` 처럼 뒤에 글자가 붙습니다. **실제로 표시된 주소**를 쓰세요.

### 2-6. 세 군데를 열어 확인

폰이든 PC 든 브라우저에서 열어봅니다.

| 주소 | 이렇게 나오면 성공 |
|---|---|
| `https://…onrender.com/api/health` | `{"status":"ok"}` |
| `https://…onrender.com/` | DormX 상태 페이지 |
| `https://…onrender.com/admin/` | 토큰 입력칸 → `ADMIN_TOKEN` 을 넣으면 사용자 목록(처음엔 비어 있음) |

### ✅ ②가 끝났는지 확인

`/api/health` 가 `{"status":"ok"}` 를 돌려주고, 그 주소를 메모장에 적어 뒀다.

### ②에서 막힐 때

| 화면에 나오는 것 | 이유와 해결 |
|---|---|
| `render.yaml` 을 못 찾음 / "No render.yaml found" | 브랜치가 `main` 입니다. 2-3 의 브랜치로 바꾸세요. |
| 로그에 `ADMIN_TOKEN 이 기본값입니다` 하고 서버가 꺼짐 | 환경변수를 안 넣었거나 이름 오타입니다. 서비스 → **Environment** 에서 세 개를 확인하세요. |
| 로그에 `could not connect to server` / `password authentication failed` | `DATABASE_URL` 문제입니다. 비밀번호가 `••••` 인 채로 복사됐거나 한 줄이 잘렸습니다. ①-3 을 다시 하세요. |
| 브라우저에 **502 Bad Gateway** | 아직 켜지는 중이거나 자고 있습니다. 30초~1분 뒤 새로고침하면 됩니다. |
| 배포는 됐는데 `/admin/` 이 404 | 주소 끝의 슬래시를 빠뜨렸습니다. `/admin/` 처럼 `/` 로 끝나야 합니다. |

> 나중에 코드를 고쳐 이 브랜치에 push 하면 **Render 가 알아서 다시 배포**합니다. 손댈 것 없습니다.

## ③ 앱에 서버 주소 넣기

`mobile/app.json` 에서 **한 줄만** 고칩니다.

```json
"extra": {
  "defaultServerUrl": "https://dormx-sleep-api.onrender.com"
}
```

저장하고 커밋합니다. (EAS 는 커밋된 내용으로 빌드합니다)

```powershell
git add mobile/app.json
git commit -m "서버 주소 설정"
```

> 설치한 뒤에도 바꿀 수 있습니다. 앱 첫 화면에서 **달 아이콘을 1초쯤 길게 누르면** 주소 입력칸이 나옵니다.

## ④ APK 빌드하기

```powershell
cd C:\Users\grace\sprint\mobile

npx.cmd eas-cli@latest login      # Expo 계정 (없으면 expo.dev 에서 무료 가입)
npx.cmd eas-cli@latest init       # 이 앱의 프로젝트 ID 를 만들어 app.json 에 넣어줍니다
npx.cmd eas-cli@latest build --platform android --profile preview
```

- `preview` 프로필은 **APK** 로 만듭니다. 스토어를 거치지 않고 바로 설치할 수 있는 형식입니다.
- 커밋 안 한 변경이 있으면 "커밋할까요?" 하고 묻습니다. `yes` 로 답하면 됩니다.
- 무료 대기열이라 10~25분쯤 걸립니다. 다 되면 **다운로드 링크와 QR 코드**가 나옵니다.
  (창을 닫아도 <https://expo.dev> → 내 프로젝트 → Builds 에서 다시 볼 수 있습니다)

## ⑤ 폰에 설치하고 확인하기

1. 폰에서 그 **QR 을 찍거나 링크를 엽니다** → `.apk` 가 내려받아집니다.
2. 열면 "이 출처의 앱 설치 허용" 을 묻습니다 → 허용 → 설치.
   (Play 스토어를 거치지 않아서 나오는 경고입니다. 5명 이하 배포에서는 이 방식이 정상입니다)
3. 앱을 열고 **회원가입** → 닉네임 2~16자, 비밀번호 4자 이상.
4. 홈 화면이 뜨면 성공입니다. 아직 기기를 안 붙였으면 시작 버튼 아래가 **"기기 미등록"(빨강)** 으로 보입니다.

여기까지가 "앱이 폰에서 도는지" 확인입니다.

## 실제 기기까지 연결해서 보려면

기기(ESP32)는 아직 **USB 로 PC 에 연결**돼 있어야 합니다. 브리지 프로그램이 시리얼 값을 받아 서버로 올립니다.

```powershell
cd C:\Users\grace\sprint
python serial_csv_logger.py --server https://dormx-sleep-api.onrender.com --api-key <INGEST_API_KEY>
```

처음이라면 시리얼 통신 라이브러리를 먼저 깝니다: `pip install pyserial`

`--port` 를 안 주면 브리지가 COM 포트 목록을 보여주고 고르라고 합니다.

**잘 되고 있으면 이런 줄이 보입니다:**

```
[연결됨] COM5 @ 115200bps
[기기 인식] DORMX-246F28AABBCC — 이 ID 로 업로드합니다.
```

- 두 번째 줄이 보이면 **앱이 알아서 그 기기를 잡습니다.** 앱을 열어 두면 몇 초 안에
  상태 칩이 초록색 "기기 연결됨" 으로 바뀌고 "기기 연결 완료 — DORMX-…" 이 뜹니다.
- 기기가 두 대 이상 잡히면 어느 것이 내 것인지 알 수 없으므로, 그때는
  **"기기 미등록"** 을 눌러 목록에서 직접 고르면 됩니다.
- 브리지는 포트를 열 때 기기에게 ID 를 직접 물어보고(`whoami`), 못 받으면 10초마다 다시 묻습니다.
  그래서 기기를 먼저 켜 두었다가 브리지를 나중에 실행해도 찾습니다.
- 그다음부터 앱의 시작 버튼이 기기의 start 를 대신합니다.

| 브리지 화면 | 뜻 |
|---|---|
| `[연결 실패] could not open port` | 포트 번호가 틀렸거나 다른 프로그램(아두이노 IDE 시리얼 모니터)이 잡고 있습니다. 그 창을 닫으세요. |
| `[연결됨]` 만 나오고 `[기기 인식]` 이 없음 | 기기가 응답하지 않습니다. USB 케이블(충전 전용 케이블 주의)과 기기 전원을 확인하세요. |
| `[업로드 실패] 401` | `--api-key` 가 Render 의 `INGEST_API_KEY` 와 다릅니다. |

> 이 USB 연결을 없애려면 ESP32 에 Wi-Fi 를 붙여 기기가 직접 서버로 올리게 해야 합니다. 필요하면 말씀해 주세요.

## 자주 막히는 곳

| 증상 | 이유와 해결 |
|---|---|
| 앱에서 "서버에 연결할 수 없습니다" | 주소 오타이거나 `https://` 를 빠뜨린 경우가 대부분입니다. 폰 브라우저로 그 주소를 열어보세요. |
| 로그인이 30초 넘게 걸림 | 무료 서버가 자다 깨는 중입니다. 정상이며 한 번 깨면 그다음은 빠릅니다. |
| Render 로그에 `ADMIN_TOKEN ...` 하고 서버가 죽음 | 토큰 환경변수를 안 넣었습니다. **2-4** 를 확인하세요. |
| `npx : 이 시스템에서 스크립트를 실행할 수 없으므로` | `npx.cmd` 로 쓰거나, PowerShell 에서 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 한 번 실행하세요. |
| 앱을 고쳤는데 폰에 반영이 안 됨 | APK 는 빌드 시점의 코드로 굳습니다. ④를 다시 돌려 새 APK 를 설치하세요. |
| 설치할 때 "앱이 설치되지 않음" | 예전 APK 가 남아 있으면 지우고 다시 설치하세요. |
| EAS 빌드가 `Run gradlew` 에서 실패 (`no member named ...`) | 라이브러리 버전이 서로 안 맞는 것입니다. `mobile` 에서 `npx.cmd expo install --check` 를 돌려 Expo 가 권장하는 버전으로 맞추고 다시 빌드하세요. 새 패키지를 추가한 뒤에 잘 생깁니다. |
